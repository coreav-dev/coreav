# coreav-hevc

An opt-in, safe Rust HEVC header inspector and scalar intra decoder written from ITU-T H.265 (V11), January 2026. `HeaderParser` inspects Main/Main10 parameter sets, VUI, SEI and slice headers without decoding entropy or samples. `IntraPictureDecoder` reconstructs one original Main 8-bit or Main10 8/10-bit intra picture and applies its signalled deblocking and SAO. Unselected pictures receive header inspection only. There is no inter prediction or production decode backend.

HEVC can require a patent licence depending on jurisdiction and use. This crate is separately packaged, unpublished, and absent from default artifacts. Its API requires the `native-hevc` feature. No CLI, Python, WebAssembly or npm default enables it. See [the design](../../docs/design/hevc.md).

The library reads no files and makes no OS calls. Callers supply original complete NAL units without framing. Both facades share one private parameter-activation, picture-identity and header-only DPB owner. Annex B and length-prefixed iterators are also available. Errors distinguish malformed input, unsupported tools and exhausted limits; every failed session is terminal.

`IntraLimits` contains header `Limits`, a total reconstruction-memory limit (default 256 MiB), and a picture-wide CABAC budget (default 268,435,456 bins). Memory includes retained parameter state, planes, availability cells, CTU filter metadata, syntax/substream storage, numerical scratch and one SAO component copy; caller-owned input storage is separate. Picture allocations are fallible and bounded. Serial tiles, WPP, dependent segments and PCM preserve their specified entropy transitions without threads. Scalar prediction, inverse reconstruction and filter equations live in the separately opt-in `coreav-kernels-hevc` crate.

The callback borrows complete coded Y/Cb/Cr `u16` planes with original index, coded/visible geometry, conformance window and effective counters. Deblocking then SAO finish before defined MD5, CRC and checksum suffix hashes are verified over coded components; reserved hashes are counted separately. Consumers must also require successful `finish`: a later error cannot revoke a picture already delivered at an earlier boundary. The untimed `intra` example and G2/G3 driver are test tools, not default CLI consumers or fallbacks. See [the in-loop design](../../docs/design/hevc-inloop.md) and [conformance commands](../../bench/hevc-conformance/README.md).
