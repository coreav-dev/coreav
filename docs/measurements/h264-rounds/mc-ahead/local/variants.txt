Prototype variants of the reference hints, one binary each with the variant chosen by environment at run time
(not kept), on perf/h264-coarse-dispatch 49a1cecc. CPU time, --discard, one thread pinned to CPU 2, the arms
rotated each round; per stream each arm's median over the first arm's ("off", no reference hints), then the
median over streams. development VM, Intel Xeon @ 2.50 GHz (not the bar class); information. "off2" is a second
"off" arm: the spread between identical arms.

Variants: every N = the blocks at a luma x that is a multiple of N ask (64: the first macroblock of each four,
at its left edge); dist D = the block's position at its own vector moved D luma samples right (chroma D / 2);
rows = the window's h + 5 rows (both ends of each row, or one hint a row) or the block's h rows (one hint a
row); luma = luma only, else luma and both chroma planes; size = all pictures, or round 12's rule (more than
1 MiB of samples).
