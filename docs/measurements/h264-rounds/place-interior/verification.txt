- place_with_the_interior_is_place_with_the_window_test_near_the_edges: place() with the Planes
  that with_origin builds against place() with the same Planes and an empty interior
  (x_last = y_last = -1, so every block goes through Windows::fit); whole Option<Placement>
  compared. Exhaustive over a bounded domain: references 2x2, 4x4, 18x18, 20x20, 20x22, 22x20,
  22x22, 24x24, 22x40, 40x24, 64x64; along one axis every integer target from 5 before the plane
  to 23 inside at each edge (and -21, -20, -13, -8, n/2, n+8, n+13, n+20, n+21), every fraction
  0 to 7, positions 0, 1, n/2, n/2+1, n, n+1; along the other a few targets around the interior's
  edges, fractions 0, 1, 4, 5 and positions 0 and 1; all nine sizes. Four reference layouts in turn
  (origin 0 with slices exactly as long as with_origin requires; a few rows and samples before;
  slack both sides with Cb and Cr of different lengths; a few samples each side), seven pictures in
  turn (whole picture, slack, a band, a band whose chroma starts a row late, slices a sample short,
  half the luma rows, a different stride), Put/Avg/Weigh in range and Weigh out of range in turn.
  9.3 million inputs: 118,689 placed through the interior, 234,796 through the window test,
  8,946,611 declined. About 2.7 s in a debug build.
- place_with_the_interior_is_place_with_the_window_test_on_random_blocks: the same comparison on
  1,000,000 inputs from a xorshift generator: 10,000 references 2 to 80 samples wide and tall with
  random slack before and after (often none), 100 blocks each: any vector up to n + 24 samples
  each way, targets within 23 samples of an edge, or targets in the plane, positions up to 8 past
  the plane, random sizes, pictures and operations. 16,290 placed through the interior, 13,686
  through the window test, 970,024 declined. About 0.5 s.
- every_window_of_a_block_inside_the_interior_fits: for references 22x22, 22x24, 24x22, 24x24,
  26x40, 40x26 and 48x48 in the four layouts, every (xi, yi) the interior holds, all nine sizes,
  all 64 fraction pairs (mv & 7 each way), and for each two positions per axis (a vector under two
  samples, and one 7 or 8 samples back from further on, so both parities appear across fractions):
  Windows built as place() builds them, Windows::fit is true.
- a_plane_narrower_or_shorter_than_21_samples_has_no_interior: for every even stride and rows from
  2 to 64 with one of them below 21, the interior with_origin stores holds no (xi, yi) in
  -40..100 squared; and Interior::of(small, other) and Interior::of(other, small) for small 0 to 20
  and other 0 to 64 (odd included) hold none either.

Rebase onto main 33e2273 (banded references on the fast path)

The branch was rebased onto 33e2273. place() keeps round 17's src.at (where sample (0, 0) would sit in
each slice, negative for a band whose first row is not 0) for luma_src and chroma_src, and this
round's interior fast path; Windows::fit tests what main's place() tested (fits, used, and held
with at). Planes::band had an empty interior in the rebased 10444f7 and has its own, narrowed to
the rows its slices hold, from 931a300 (the code commit; production code unchanged since):
x_last = stride - 19, y_first = max(first[0] + 2, 2 * first[1] + 1),
y_last = min(rows - 19, first[0] + n[0] - 19, 2 * (first[1] + n[1]) - 17), n[0] = (len(y) -
origin[0]) / stride and n[1] = (min(len(cb), len(cr)) - origin[1]) / (stride / 2), each at most
rows (Interior::band; derivation in its doc comment and in docs/design/h264.md).
