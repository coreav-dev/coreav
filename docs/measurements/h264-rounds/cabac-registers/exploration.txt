Exploratory timings, not bar runs: cloud containers (2 CPUs; the CPU model is not visible inside them, so not a bar
class), one container per training stream (32), every binary of the run in the same container in a shuffled order each
round after one warm-up decode each, decode --discard at the class's frame count (sd 1800, 720p 900, 1080p 300, 4k 150).
Wall-clock per decode; per stream the ratio of medians to the run's base, then the median over streams with a 95%
bootstrap interval (2,000 resamples). They chose what the round builds; the bars of docs/design/h264.md decide it.
