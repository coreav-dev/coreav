# Codecs

H.264, AAC, Opus, VP9, AC-3, MP3, and AudioToolbox behavior.

| Rule | Enforced by |
|---|---|
| Lossy decoder admission cannot claim unproved exactness or reference a missing evidence heading | `audio_decoder_eligibility.py` accepts only conformance rows and reads headings through the pinned Markdown parser; changed-kind, missing-anchor, fence-delimiter, list-fence and indented-code regressions run in `deny.yml`. The parser owns block syntax instead of a second handwritten fence state. Documentation content is external to the JSON type |
| AAC decoder admission requires its applicable ISO acceptance procedure, not just ISO vectors judged by project waveform thresholds | `audio_decoder_eligibility.py` refuses AAC eligibility until that procedure is registered; `test_aac_project_comparator_cannot_grant_iso_eligibility` rejects a changed pass flag. Matching a procedure to the standard needs specification review; a type cannot prove the meaning of a normative criterion |
| G1 hash ordering counts identical prepared bytes once, regardless of parent, with an encoder-blind representative chosen before slot selection | Not enforced: judgment until freeze tooling exists. The duplicate rule in `docs/design/h264-encoder.md` orders representatives by full-original SHA-256 and stable parent identifier, refuses an unresolved tie and excludes other copies from all slots. Prose cannot prove external byte identity |
| VP9 decoding budgets retained capacities and all new packet allocations, including copied outputs, before publishing frame state | `Memory` owns checked charges and fallible buffer creation; the fixed reference pool and inline parse/counter state remove shared and boxed allocation. Boundary, eight-reference, output-copy, resizing and partial-superframe tests run with the crate tests. Crate clippy rules reject production `Box`, `Arc`, `Rc` and infallible reserve methods; they cannot identify every future allocating iterator or deep clone, so keeping those out of decoder paths remains review judgment |
| G1 checkpoints publish only complete, durable JSON and never replace a completed cell under a recovery disposition | `publish_json` fsyncs a same-directory temporary file, renames it under a directory lock, and fsyncs the directory. Runner-loss regressions interrupt on both sides of rename, recover retained truncated legacy JSON only with a bound fault, and refuse replacement of completed cells even when validation fails |
| G1 conformance preserves the oracle's native planar format and retains process failure diagnostics, including timeouts | One shared `capture` owns conformance and measurement process records, including the decoder's streamed binary output. `test_full_range_native_pixel_format_is_not_converted` rejects wrong range, format, or geometry; failure and timeout regressions retain partial output and status, re-raising the original timeout instead of accepting it |
| Small G1 pictures retain the level's access-unit envelope instead of an unregistered fraction of their raw size | `a_small_textured_picture_uses_the_level_ceiling_not_a_raw_size_fraction` encodes a one-macroblock picture above 192 NAL bytes, while preserving a caller's explicit smaller bound |
| The JM downloader supplements a missing intermediate only from the exact pinned certificate and a chain to existing roots; it never disables TLS verification | The bundle consumes a single PEM reconstructed from validated DER, not the downloaded multi-certificate input. `test_jm_bundle_drops_a_trailing_unpinned_certificate` proves an appended synthetic CA stays untrusted; `test_jm_archive_fetch_requires_pinned_and_root_verified_intermediate` refuses hash or root-validation failures before archive fetch |
| G1 VUI colour combinations obey the specification, and cached RD summaries are replayed from complete raw metric output | `unspecified_primaries_cannot_signal_derived_colour_matrices` rejects forbidden derived matrices; `test_aggregate_mutation_and_missing_metric_detail_fail` requires 60 finite frame scores, their arithmetic mean, chroma scores, and replayable process records. The conformance harness rejects CoreAV oracle diagnostics even on a zero exit |
| Native packed S24 conversion keeps its single-rounding contract; FFmpeg-exact sample-format tests cover S16, S32 and F32 rather than treating PCM24 packing as an S24 sample format | `float_to_s24_rounds_once_at_the_stored_width` derives native half-LSB and clipping bytes independently; `sample_conversion_is_exact_against_the_pinned_oracle` compares complete S16/S32/F32 output bytes with the verified oracle and requires it in CI. The documentary PCM24 difference adds no acceptance predicate |
| AudioToolbox native fixtures append source PCM or begin drain only at `Flow::NeedInput`, pulling pending `Flow::More` output first | The `flow == Flow::NeedInput` append branch and pre-drain assertion in `native_four_cells_drain_and_decode_with_the_independent_rust_decoder` (`coreav-backend-apple/src/audiotoolbox/tests.rs`) enforce the fixture's ordering; it runs in `encoder-backends.yml` on hosted macOS |
| H.264 output metadata accepts unspecified Extended_SAR and keeps SEI before, and filler after, the first VCL NAL | `vui` and `AccessUnit::copy_from` own these checks; zero-SAR and auxiliary-NAL ordering regressions in `coreav-backend-apple/tests/h264_output.rs` run on hosted macOS. Types cannot establish external bitstream order |
| One-IDR admission uses fresh bounded state and the activated SPS geometry before picture start, refuses empty framed NALs and never releases output after failure | The codec owns header preflight and the geometry callback; its terminal state, strict framing policy and exact-coverage check are exercised by `coreav-backend-h264/tests/one_idr.rs`, including retained streaming scratch, undrained output, empty/truncated framing and the counting-allocator caller veto. The shared length-prefix reader owns both framing policies so normal streaming stays unchanged |
| An H.264 encoder timing contract names the exact VUI field values and their representability, not only a frame rate | Not enforced: judgment until the encoder exists. The G1 design fixes nominal timing to `num_units_in_tick = 1`, `time_scale = 60`, and `fixed_frame_rate_flag = 1`; future writer tests must check the emitted fields |
| A public VP9 kernel input cannot leave the specification's domains: samples are `u8` or `u16`, and transform sizes, bit depths, coefficients, filter strengths and edges exist only through their checked constructors | The sealed `Pixel` and the checked types of `coreav-kernels-vp9` (`TxSize`, `BitDepth`, `Coefficients`, `BlockMut`, `Strength`, `Edge`). The `compile_fail` doctest on `Pixel` refuses a sample type from outside the crate; `every_value_a_sample_holds_filters_without_overflow` and the transforms' domain tests run every value the types allow (`cargo test --workspace`, `ci.yml`). A check inside a kernel would leave the next kernel open to the same input |
| The VP9 decoder reads no environment variable: what it decodes depends on its input and `Limits` alone | `disallowed-methods` in `crates/coreav-vp9/clippy.toml` (`cargo clippy --workspace --all-targets`, `ci.yml`); `tests/clippy_config.rs` keeps that file in step with the workspace's. The harness reads its vectors' directory through one `#[expect]`ed function |
| Code is written from specifications, never from other implementations' source | The code-similarity check for `coreav-h264`, `coreav-kernels-h264`, `coreav-opus`, `coreav-kernels-audio`, `coreav-vp9` and `coreav-kernels-vp9` (`docs/design/ci-checks.md`, "Before opening a pull request"); elsewhere review |
| High-rate signed-16 WAV preserves its declared speaker layout | `wav::header` owns the extensible-header decision above 48 kHz. `high_rate_integer_headers_store_the_known_speaker_layout` checks stored fields across the boundary, and `scripts/raw_pcm_check.py` compares the actual mono/stereo WAV fields with the pinned oracle. A type cannot distinguish two otherwise valid WAV header representations |
| Raw PCM arithmetic preserves fused F32 rounding without adding a C math dependency to the default CLI | `finite_fused_arithmetic_matches_single_rounding` checks finite stored bits, including double-rounding midpoints; `raw-pcm` checks the built CLI's ELF dependencies and refuses `libm`. The unchanged startup instruction guard checks the whole command. Types cannot establish external linkage |
| Native FLAC correctness coverage exercises linear prediction, not only fixed predictors | `Subframe::plan` owns end-tapered autocorrelation. `coding_choices_include_linear_prediction_and_partitioned_rice` requires an LPC choice for the tonal fixture, while complete roundtrips check every sample and MD5 (`flac-output.yml`, `ci.yml`). A type cannot prove a signal-dependent bit cost |
| Native FLAC residual costs include both legal parameter widths and escaped partitions, with the same bits charged and written | `Rice::plan` owns exact method and partition selection; exhaustive-choice and wire regressions compare every charged bit, signed residual and tie, including parameters 0, 14, 15 and 30 and escape widths 0, 1 and 31. Complete escaped and five-bit fixtures require pinned independent decoding in `flac-output.yml`. Private partition variants distinguish Rice parameters from signed escaped widths; types cannot prove a signal-dependent minimum |
| FLAC residual-loop optimization preserves complete encoded bytes | `Predictor::residual` owns fixed and linear construction, and the stream owns reusable scratch. Scalar regressions cover every order and shift; `flac_output_identity.py` compares complete fixture files against the pinned residual-coder baseline in `flac-output.yml`, rejecting incomplete inventories and changed bytes even when reported digests match. Safe ownership separates chosen residuals from scratch; types cannot prove equal arithmetic or compressed bytes |
| FLAC's integer coefficient shift does not load a transcendental math routine into every CLI startup | `lpc_shift` owns the bounded power-of-two search; `linear_coefficient_shifts_respect_exact_power_of_two_boundaries` checks each boundary and adjacent floats. The unchanged startup instruction guard catches linked-code costs, and its linkage/profile diagnostics identify library loading. A coefficient type cannot constrain the final binary's dynamic dependencies |
| Native FLAC retains back-surround speaker identity instead of relying on an ambiguous five- or six-channel default | The encoder's `header` owns the RFC 9639 channel-mask comment; `back_surround_layouts_have_an_explicit_rfc_channel_mask` checks its bytes and full empty, tiny and multi-block decoding. The CLI gate compares source and output probe layouts for both widths and the tiny-reference boundary. Channel count alone cannot encode back-versus-side identity |
| Native VP9 admits absent profile metadata for packet-time validation, but never retries another backend after a packet fails | One `scope` function governs selection and direct open; `selection_admits_absent_metadata_without_retrying_after_packet_failure` checks both absent metadata and a known unsupported profile. The design's Scope section links to its single backend-admission contract instead of repeating it; arbitrary prose consistency remains review judgment |
| A public decode limit error ends the session even when the wrapper rejects before reaching the backend | `Checked::call` owns all packet, EOF and receive operations and drops its optional backend on every `Limit`, while retaining metadata prepared at open. Public-open VP9 packet, wrapper frame and backend-operation regressions reject draining, retry and EOF after failure and check immediate backend release; a backend-only latch cannot observe wrapper refusals |
| H.264 encoder candidates obey Annex A's 3,200-bit `macroblock_layer` limit before mode selection, independently of access-unit byte budgets | The shared `macroblock` syntax traversal enforces the bound for counting and emission. `dense_low_qp_content_is_refused_without_advancing_sequence_state` rejects the original oversized input and verifies rollback; the separate admissible access-unit fixture retains the >192-byte assertion and caller-budget refusal. Decoder sample equality cannot establish this level constraint |
| Native H.264 frames carry the colour of their activated SPS rather than a frozen stream header or the most recently parsed SPS, without turning absent signalling into explicit output metadata | `Picture::with_output` copies the active VUI colour before sharing the picture, and the backend builds `Frame.color` only from that immutable snapshot. Optional signalling fields preserve absence; `vui_retains_picture_colour_and_infers_absent_fields` covers every retained field and its defaults. The real mid-stream colour fixture in the required FFV1 gate checks terminal failure, destination preservation and no fallback in both strict modes; `raw_file_pipe_and_y4m_keep_every_decoded_sample` checks unchanged output metadata. Copy-owned picture metadata prevents reordering from relabelling an older picture |
| Rendering raw native H.264 picture colour retains applied container fields where declarations are absent, including the container chroma location | The shared `frame_color` boundary owns inheritance for ordinary and bounded thumbnails and CLI frame output. `h264_picture_colour_inherits_only_missing_applied_fields` checks precedence, `h264_thumbnail_inherits_applied_container_colour` checks prepared image bytes and `image_output_inherits_h264_container_colour_without_vui_signalling` checks a real native decode with a container-only colour box. Inheritance cannot live in the decoder because FFV1 needs raw declarations to detect changes |
| Native FFV1 preserves every admitted sample and frame without an external encoder or hidden pixel conversion | Fixed codec settings and the separate Matroska job own admission; bounded codec and adapter regressions cover packet, allocation, timeline and format failures. The required CI check decodes native output with the pinned oracle and compares every frame byte and the explicit probe fields; comparator mutation tests reject changed pixels, clocks, fields and incomplete output |
