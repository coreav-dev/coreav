## HEVC decoding and planning

| Rule | Enforced by |
|---|---|
| Main10 admission is not vetoed by an additional eight-bit-only compatibility claim; an inconsistent claim warns without changing samples | The shared `Profile` owner retains Main10 support separately from eight-bit compatibility claims, and `Warnings::profile_bit_depth` reports the contradiction. `main10_admission_is_not_vetoed_by_an_eight_bit_compatibility_claim` checks exact existing-fixture samples and warning presence at both depths; `profile_admission_preserves_depth_limits_and_requires_a_main10_claim` retains unsupported-depth and missing-Main10 refusals. Types cannot prove that external claims agree with coded sample depth |
| A later HEVC CU QP delta preserves earlier CUs in the quantization group while covering every TU of its own CU | `Cu` retains its area and `delta_qp` updates only that area, rather than the quantization-group footprint. `a_later_qp_delta_preserves_earlier_cus_and_updates_the_entire_current_cu` checks earlier CUs, an already reconstructed zero TU in the current CU, future CUs and one-time delta consumption. H.265 clauses 8.4.1 and 8.6.1 derive QpY per CU; a type cannot prove external syntax timing |
| A VPS transition must qualify as a CVS start before any CVSG state reset | `Dpb::start_cvsg` uses the single `starts_cvs` owner on the existing state, so resetting `after_eos` cannot manufacture a boundary. `vps_change_cannot_turn_an_ordinary_cra_into_a_cvs_start` rejects a no-EOS CRA without output; the existing prior-output matrix uses a preceding EOS for its legal CRA control. A type cannot derive a temporal boundary from external NAL ordering |
| All segments of a HEVC picture preserve common header syntax, and every IRAP slice is intra | `slice::parse` rejects non-intra IRAP syntax and produces a fixed-size, bit-alignment-independent identity of the bounded reference-syntax region, including selector paths, long-term counts and temporal MVP. `HeaderParser` compares it for independent segments and checks the prior-output prefix for dependent segments too. Wire regressions reject changed references, equal-derived/different-signalled long-term lists, temporal MVP and prior-output flags while preserving matching offset-normalized syntax and legal non-IRAP I/P mixtures. Syntax identity keeps one owner rather than duplicating the field list; types cannot establish equality across external NAL units |
| A HEVC VPS change applies the new IRAP's prior-output rule instead of unconditionally draining the DPB | `Dpb::start_cvsg` validates the IRAP before any callback and shares the private `prior_output` owner with ordinary CVS starts; CVSG reset is private. `vps_change_obeys_new_picture_prior_output_flags` checks discard and output for BLA/IDR/CRA, `vps_change_requires_an_irap_before_releasing_prior_output` rejects a non-IRAP without output, and the CVSG callback/finished-state regression prevents reopening failed or ended sessions. A type cannot establish an external bitstream's flags, so the one transition owner enforces them |
| The active HEVC SPS ID and full content remain fixed throughout a coded video sequence | `HeaderParser` retains the active SPS identity and rejects a change before new-picture DPB processing; `Dpb::starts_cvs` alone owns the IRAP/NoRaslOutputFlag boundary used by both activation and POC. `first_slice_cannot_change_the_sps_identity_inside_a_cvs` rejects same-slot changes and new IDs for TRAIL and non-starting CRA, while `a_new_cvs_can_activate_a_different_sps_identity` permits IDR and CRA after EOS. A type cannot establish a temporal bitstream lifetime, so the single state owner and wire regressions enforce it |
| HEVC parameter-set NALs between slice segments retain the current picture for identical active repeats and changes to unused IDs; a changed used set requires a new first slice | `HeaderParser` owns active PPS/SPS/VPS IDs and fixed-slot full-RBSP identities. The repeated-set, unused-ID replacement and changed-active-set wire regressions in `coreav-hevc/src/tests.rs` exercise all three set types. Ownership centralizes invalidation; types alone cannot establish external NAL content or ordering |
| Serial tile, WPP and dependent-segment traversal and entropy state precede universal intra-picture hash gates, independently of parallel scheduling | Not enforced: review of milestone dependencies against H.265 clauses 9.3.1 and 9.3.2.1. The HEVC plan puts serial semantics in milestone 2 and requires coverage by G3; milestone 6 adds scheduling only. Types cannot establish the dependencies of a prose plan; the future conformance harness must enforce its feature coverage |
| A selected native HEVC session ends after any failed packet, EOF or receive operation, releases its queued frames and never opens a fallback, even when opened directly | `NativeDecoder` in `coreav-backend-hevc` owns the terminal state for every operation, independently of `coreav_decode::Checked`. `selected_native_errors_never_open_a_fallback`, `malformed_or_multi_picture_access_units_close_and_discard_queued_output` and `a_packet_after_eof_fails_and_drops_unreceived_frames` cover the wrapper and direct paths; the boundary fuzz target asserts that every operation after a failure fails. External packet content cannot be constrained by a type |
| Native HEVC thumbnails decode every packet from the selected start, drain the selected access unit and refuse a missing target, while every other route keeps its disposable-packet shortcut and early stop | `decode_through` gates the route on the HEVC codec and the selected `Native` backend kind. `only_native_hevc_decodes_every_packet_and_drains_the_selected_access_unit` records the packets, discard flags and EOF for native HEVC, fallback HEVC and native H.264, including a missing target and a late EOF error. | A HEVC configuration record is admitted only with at most 64 distinct arrays, 4,096 initialization NALs, a one-, two- or four-byte length size and no trailing bytes | `Configuration::parse` owns the caps before any allocation; `invalid_configuration_and_other_codecs_are_never_admitted` covers each refusal and the admitted shapes. External container bytes cannot be constrained by a type |
