# Containers

ISO BMFF, Matroska, MPEG-TS, and AVI.

| Rule | Enforced by |
|---|---|
| An MPEG-TS packet declaring both adaptation and payload contains at least one payload byte | `ts_output::tstd::header` rejects adaptation length 183 for adaptation-field control 3; `adaptation_with_payload_requires_at_least_one_payload_byte` mutates a valid serialized packet and requires refusal. A byte slice's type cannot express the conditional wire-length rule |
| Compatibility video copy from several contributing inputs validates each selected source timeline and uses complete packet order, while native defaults retain their old layout | The mapped CLI plan enables both policies only after resolving contributors; `remux_mp4_inputs_with_options` reuses the source-specific list pass and shared scheduler. `contributing_inputs_preserve_complete_packet_order_and_decoded_output` checks complete ordered packets, frames, metadata, decoded bytes and atomic fallback; `mapped_input_policies_preserve_defaults_and_apply_source_timing_admission` checks unchanged defaults, both source positions and existing budgets. Types cannot prove input sample/edit validity |
| A Matroska early scan that stops at a packet or span cap with audio/video windows pending cannot certify a complete input summary | `early_packets` marks span stops incomplete and uses one bounded packet-header lookahead to distinguish a packet cap from actual EOF. `summary_distinguishes_early_scan_caps_from_end_of_input` covers both caps, short/exact-cap EOF and completed windows; generated `mkv-analysis-packet-cap` checks atomic refusal and exact pinned fallback in all three spellings. Existing element-work and retained-packet bounds remain; a counter limit alone cannot prove EOF |
| Input-seek compatibility must not inherit native clipping's gapless origin or partial-sample edit bounds | `clip_mp4_input_seek` admits only video without retained composition offsets, several edits, a shifted cut point or an incomplete packet endpoint, using the existing plan/tables before writing. `input_seek_admission_uses_the_retained_packet_tables` checks byte-empty refusals and identical native defaults; the pinned CLI regression checks exact packets, frame timing, pixels and preserved fallback. The native entry point and limits stay unchanged; a reported decoder reorder count cannot prove packet-table eligibility |
| A simple edit alone does not establish exact compatibility-copy timing: its endpoint must cover the complete copied presentation, except for trimming within the final AAC sample | The bounded remux `list` compares exact cross-multiplied clocks against sample endpoints. Overlong AAC edits can be shortened only to an end exactly representable in the source movie clock; other out-of-range ends refuse. `rebuilt_durations_refuse_shortened_and_extended_simple_edits` and `rebuilt_durations_clamp_exact_extended_aac_edits_without_changing_samples` cover refusal, canonicalization and unchanged native behavior. Pinned `ordinary_copy_refuses_trimmed_simple_edits` checks video, AV, audio, final-frame cuts, extended edits, destination preservation and byte-identical fallback. Input-dependent sample endpoints cannot be proved by the edit enum or a static type |
| Compatibility video-origin normalization requires the first decode-ordered sample to have the earliest composition time; a minimum by itself cannot establish the external demuxer's origin | The bounded remux `list` owns the pre-output guard. `video_origin_requires_the_first_decoded_sample_to_present_first` and the pinned `copied_video_refuses_a_later_sample_before_its_first_composition` regression enforce refusal and exact fallback. Composition order depends on input packet tables, so a static type cannot prove this admission fact |
| Compatibility copy derives header durations from copied samples and edits instead of preserving conflicting declarations; native remux retains its separate default preservation policy | The remux table pass preserves overrides only when neither duration rebuilding nor an origin is selected. `rebuilt_durations_keep_samples_edits_and_native_header_policy` checks the native boundary, and pinned `ordinary_copy_rebuilds_declared_durations_for_video_and_audio` covers edited and unedited AV, video, short, long and unspecified declarations. A duration's integer type cannot establish agreement with input samples |
| A flood of empty Matroska zlib frames has input-linear source reads, with inflation bounded separately by the per-frame charge, rather than a shared-runner time limit | `a_flood_of_empty_zlib_frames_is_bounded` caps sized listing reads at twice the input bytes and plain listing and index reads at the input bytes each; its known-size count checks the unchanged inflation budget. A source counter observes rereads that output counts alone cannot detect |
| Skipping an oversized ISO track-reference box clears metadata completeness; an incomplete snapshot cannot produce a known stream-group count | The reader's existing `tref` size boundary owns the completeness flag, and the adapter carries `Option<usize>`. `an_oversized_reference_marks_metadata_incomplete` and `incomplete_references_do_not_become_a_known_zero_group_count` check both sides of the bound and strict-safe refusal for JSON/default requests |
| A bounded tail timestamp survives an unknown unit duration, and retries preserve observations without mixing selected end/timestamp pairs | `TailEnds::fill_from` owns pair adoption and last-only maxima; `tail_retries_preserve_observations_and_selected_pairs` and `ffprobe_ts_tail` cover empty retries, a resolved longer window, a known shorter pair and configured/unknown clocks. Clock availability is a runtime property |
| AVI video clock expansion accounts for empty chunks in work, index and file budgets, preserves the final frame's slots and invokes payload callbacks only for real packets | `coreav_avi::plan` owns the expanded chunk count before allocation; `video_clock_slots_include_empty_chunks_in_offsets_lengths_and_budgets` checks offsets, final padding, callbacks and work/index limits; `empty_video_slots_are_charged_to_the_file_limit_using_only_metadata` checks rejection when an empty slot crosses the total-file or media-list limit |
| MP3 encoder faults keep backend, timeout, limit and I/O classification rather than becoming an unsupported-input refusal | `Failure::Encode` owns the mapping; the broken-encoder case in `scripts/avi_fixture_check.py` checks the real command's error kind, exit status and preserved destination (`avi-output.yml`) |
| AVI fixture verification runs when its MP3 module declaration or shared encoder transport changes | `test_module_and_transport_changes_run_the_avi_gate` in `scripts/tests/test_avi_workflow.py` checks the workflow filter against the module, implementation, transport and CLI test paths |
| AVI codec mapping fields have a public specification clause or an explicit pinned-binary observation, including values outside decoded-output comparisons | Not enforced: judgment. The field trace in `docs/design/avi-write.md` distinguishes format requirements, implementation bounds and interoperability choices; types cannot prove documentary provenance |
| State kept per PID in `coreav-mpegts` is bounded: by a limit of `Limits`, or by the 8,192 PIDs a packet can name | `PidMap` (`crates/coreav-mpegts/src/pid_map.rs`): `PidMap::streams` and `PidMap::programs` take their limit from `Limits`, `PidMap::pids` the PID space; `disallowed-types` in `crates/coreav-mpegts/clippy.toml` refuses the standard maps elsewhere in the crate (clippy, `ci.yml`) |
| An access unit keeps the PES identifier where it starts through video-run release, audio-frame splits and EOF | Mixed-identifier regressions in `coreav-mpegts/tests/captures.rs`, for the default and ffprobe listings; the optional packet field also represents sections with no PES identifier, so its type alone cannot enforce provenance |
| Missing FLAC or ALAC configurations, invalid FLAC block-size bounds, and unsupported ALAC cookie versions produce a malformed-configuration warning, not configured audio values | `a_malformed_lossless_configuration_is_refused` in `coreav-isobmff/tests/audio_layouts.rs`; the library parses these bytes before exposing configured values, and `coreav_isobmff::lossless_config` is the one parser of them (the writers read the sample description's values or call it) |
| M4A extraction with copied metadata preserves each header's distinct creation and modification times, widening the header when either requires 64 bits | `source_creation_and_modification_times_stay_distinct` in `coreav-isobmff-write/tests/extract.rs` checks stored values in both header versions and the metadata-clearing modes |
| A Matroska writer omits Duration when no positive presentation end is known, including negative-only or fully trimmed packets | The writer's Info serializer owns the positive-value guard; `nonpositive_presentation_ends_omit_duration_without_losing_packets` checks both supported timelines and the absence of the Duration element in the actual bytes, because the reader can silently omit an invalid zero |
| Matroska source output preserves ISO edit windows, binds Opus pre-skip to its effective leading trim and drops wholly padded replacement tails | `mkv_output::config::set_delay` owns OpusHead and CodecDelay together. The public-probe regressions in `coreav-isobmff-write/tests/mkv_output.rs` cover empty edits, finite audio/video windows, both Opus trim orderings and trailing replacement packets. External sample tables require runtime checks rather than types |
| Replaced tracks need no source copy mapping, and copied QuickTime sound-packet units are not frames | `mkv_output::source` accepts prepared replacement headers before copy validation and refuses `sound_packet` descriptions; the unmapped-replacement and sound-packet regressions in `coreav-isobmff-write/tests/mkv_output.rs` cover both boundaries |
| An ISO edit's nanosecond end-to-preroll distance fits unsigned width even when it exceeds signed timestamp width | `i64::abs_diff` owns the full-width distance in the Matroska adapter; `extreme_edit_boundaries_refuse_without_overflowing_the_preroll_distance` exercises a parsed version-1 edit with timestamps at opposite signed extremes and rejects the empty output without a panic. The unsigned result type prevents signed subtraction overflow |
| Matroska adapter metadata is charged before duplication, including repeated stream selections, and transfer to the packet writer moves its ownership | `mkv_output::MetadataBudget` owns pre-allocation charges in both source adapters and replacement preparation. The exact-limit unit test, pre-packet-traversal refusal, ISO duplicate-header regression and moved header collection prevent the late-bound-copy mistake; input-dependent byte counts need runtime checks rather than types |
| Copied audio the Matroska writer cannot map is refused before any video encoder starts, with the writer's error | `mkv_output::copied_audio` is the adapter's mapping check, called from `encode::check_source` before `output::to_file`. `unmapped_copied_audio_is_refused_before_matroska_encode` and `ffmpeg_refuses_unmapped_copied_audio_before_the_encoder_starts` require that refusal, exit 4, no encoder process and no output (`ci.yml`) |
| Bounded thumbnail planning charges full new backing capacities before allocation and keeps one account through parser and selector fallbacks | `PlanningBudget` owns checked monotonic charges and fallible reservations; parser, fallback and candidate regressions exercise its shared sticky failure. The capacity proof is tied to the distribution compiler; a later compiler needs that proof checked again |
| Optional planning preflight leaves ordinary native vector growth to its existing push or extend operation | The `None` arms and no-preallocation regressions in both planning owners preserve that split; charged `Some` paths retain full-capacity reservation and sticky failure. The instruction guard checks the native cost, including branch-local packet-header/SEI scratch and the short-parameter-set RBSP path; its prefix regression preserves both scratch branches' parsing bound |
| ISO user-data names retain their track/movie scope, text decoding and dictionary order; incomplete snapshots cannot establish requested names | The metadata walk owns header/media item positions, and the adapter reuses one name decoder and `Dict` overwrite behavior. `ffprobe_track_names` covers selection, scope, empty/duplicate/Unicode names, early/late ordering and pre-output refusal under existing limits; runtime completeness and box order cannot be established by a text type |
| ISO name decoding selects its encoding before NUL truncation from the original payload length, and refuses unsupported replacement or short-text truncation instead of approximating it | The shared decoder returns `Option<String>`, and one report support fact gates names before writer or packet output. `name_encoding_uses_the_full_payload_length_before_nul` checks both scopes against pinned byte controls; `unsupported_name_encodings_refuse_before_output_but_not_unrelated_fields` covers BOMs, invalid sequences and short expansion. A type cannot establish an external binary's decoding rules, so the owner enforces admission and the regressions preserve the observed values |
