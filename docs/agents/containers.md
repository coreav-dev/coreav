# Containers

ISO BMFF, Matroska, MPEG-TS, and AVI.

| Rule | Enforced by |
|---|---|
| MP3 encoder readback audits the entire spool, rejects auxiliary/state changes and verifies frame timing within Matroska quantization, under the encode deadline | `Packets::with_audit` owns the full-file walk; packet fields retain `CodecState` and block additions for the MP3 boundary to reject. `full_output_structure_auxiliary_data_and_timestamps_are_checked` covers appended bytes/segments, additions, codec state, duration and reordered timestamps. `TimedSource` checks cached parser reads too; `readback_checks_the_deadline_inside_parser_reads` requires timeout classification and at most one underlying read after a controlled deadline crossing |
| AVI video clock expansion accounts for empty chunks in work, index and file budgets, preserves the final frame's slots and invokes payload callbacks only for real packets | `coreav_avi::plan` owns the expanded chunk count before allocation; `video_clock_slots_include_empty_chunks_in_offsets_lengths_and_budgets` checks offsets, final padding, callbacks and work/index limits; `empty_video_slots_are_charged_to_the_file_limit_using_only_metadata` checks rejection when an empty slot crosses the total-file or media-list limit |
| MP3 encoder faults keep backend, timeout, limit and I/O classification rather than becoming an unsupported-input refusal | `Failure::Encode` owns the mapping; the broken-encoder case in `scripts/avi_fixture_check.py` checks the real command's error kind, exit status and preserved destination (`avi-output.yml`) |
| AVI fixture verification runs when its MP3 module declaration or shared encoder transport changes | `test_module_and_transport_changes_run_the_avi_gate` in `scripts/tests/test_avi_workflow.py` checks the workflow filter against the module, implementation, transport and CLI test paths |
| AVI codec mapping fields have a public specification clause or an explicit pinned-binary observation, including values outside decoded-output comparisons | Not enforced: judgment. The field trace in `docs/design/avi-write.md` distinguishes format requirements, implementation bounds and interoperability choices; types cannot prove documentary provenance |
| State kept per PID in `coreav-mpegts` is bounded: by a limit of `Limits`, or by the 8,192 PIDs a packet can name | `PidMap` (`crates/coreav-mpegts/src/pid_map.rs`): `PidMap::streams` and `PidMap::programs` take their limit from `Limits`, `PidMap::pids` the PID space; `disallowed-types` in `crates/coreav-mpegts/clippy.toml` refuses the standard maps elsewhere in the crate (clippy, `ci.yml`) |
| An access unit keeps the PES identifier where it starts through video-run release, audio-frame splits and EOF | Mixed-identifier regressions in `coreav-mpegts/tests/captures.rs`, for the default and ffprobe listings; the optional packet field also represents sections with no PES identifier, so its type alone cannot enforce provenance |
| Chapter-picture packets include their sample bytes when a decoder requests them, just like regular samples | The payload request in `IsoPackets::visit`'s chapter-picture path; `chapter_picture_packets_include_requested_payloads` (`ci.yml`) |
| Missing FLAC or ALAC configurations, invalid FLAC block-size bounds, and unsupported ALAC cookie versions produce a malformed-configuration warning, not configured audio values | `a_malformed_lossless_configuration_is_refused` in `coreav-isobmff/tests/audio_layouts.rs`; the library parses these bytes before exposing configured values, and `coreav_isobmff::lossless_config` is the one parser of them (the writers read the sample description's values or call it) |
| M4A extraction with copied metadata preserves each header's distinct creation and modification times, widening the header when either requires 64 bits | `source_creation_and_modification_times_stay_distinct` in `coreav-isobmff-write/tests/extract.rs` checks stored values in both header versions and the metadata-clearing modes |
| A source I/O or limit error in an ISO sample scan fails what the scan feeds: the report for first-packet and audio-priming scans, the listing before its first packet for decode-time-shift and edit scans; malformed samples keep their quiet outcomes, and splice-work exhaustion keeps the library listing | `quiet` owns error classification and `IsoPackets.prepared` prevents listing with incomplete plans. The regressions in `coreav-cli/tests/ffprobe_scan_errors.rs`, `ffprobe_limits.rs` and `ffprobe::iso::tests` check report failures, zero packet callbacks, malformed samples, source I/O and splice-work fallback. A lint cannot distinguish the scans' different quiet outcomes |
| A Matroska writer omits Duration when no positive presentation end is known, including negative-only or fully trimmed packets | The writer's Info serializer owns the positive-value guard; `nonpositive_presentation_ends_omit_duration_without_losing_packets` checks both supported timelines and the absence of the Duration element in the actual bytes, because the reader can silently omit an invalid zero |
| Matroska source output preserves ISO edit windows, binds Opus pre-skip to its effective leading trim and drops wholly padded replacement tails | `mkv_output::config::set_delay` owns OpusHead and CodecDelay together. The public-probe regressions in `coreav-isobmff-write/tests/mkv_output.rs` cover empty edits, finite audio/video windows, both Opus trim orderings and trailing replacement packets. External sample tables require runtime checks rather than types |
| Replaced tracks need no source copy mapping, and copied QuickTime sound-packet units are not frames | `mkv_output::source` accepts prepared replacement headers before copy validation and refuses `sound_packet` descriptions; the unmapped-replacement and sound-packet regressions in `coreav-isobmff-write/tests/mkv_output.rs` cover both boundaries |
| An ISO edit's nanosecond end-to-preroll distance fits unsigned width even when it exceeds signed timestamp width | `i64::abs_diff` owns the full-width distance in the Matroska adapter; `extreme_edit_boundaries_refuse_without_overflowing_the_preroll_distance` exercises a parsed version-1 edit with timestamps at opposite signed extremes and rejects the empty output without a panic. The unsigned result type prevents signed subtraction overflow |
| Matroska adapter metadata is charged before duplication, including repeated stream selections, and transfer to the packet writer moves its ownership | `mkv_output::MetadataBudget` owns pre-allocation charges in both source adapters and replacement preparation. The exact-limit unit test, pre-packet-traversal refusal, ISO duplicate-header regression and moved header collection prevent the late-bound-copy mistake; input-dependent byte counts need runtime checks rather than types |
