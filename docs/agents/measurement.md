# Measurement

Speed rounds, bars, thresholds, capacity, and measurement hosts.

| Rule | Enforced by |
|---|---|
| No change makes a guarded command run more instructions without a stated cost | `bench-guard` in `ci.yml` fails when a case counts more than the tolerance above its count (5%, `tolerance` in `bench/guard/baseline.json`): a pull request against its base, `main` against the baseline. A rise within the tolerance passes, and a change that moves the baseline only gets a warning: that its cost is stated is review judgment |
| An H.264 speed round's bars are judged on every stream of its set | `scripts/h264_parity.py` records requested and failed streams; `scripts/h264_parity_bars.py` refuses incomplete reports |
| A new round adds no copy of an analyzer under `docs/measurements` | `scripts/tests/test_measurement_analyzers.py` (`deny.yml`) |
| Thresholds are committed before the run they judge | Not enforced: judgment (the commit before the run is the evidence) |
| A support report labels an inapplicable predicate as such, never as a measured fraction | Not enforced in this repository: judgment. Applicability and measured support are separate facts; a count of cases cannot establish a predicate that does not exist |
| A diagnostic source variant's unit tests are checked with the feature that compiles its changed code before freezing | Not enforced: judgment. The recorded plain/count VP9 snapshots retain their test defect and a separate post-snapshot repair, rather than changing measured source identities |
| A VP9 release-cost comparison uses exactly the ten frozen inputs, by full SHA-256 and in order, in capture and replay; a VP9 attribution report requires its configured caps, real frame counts and complete pixel, counter and profile work, and remains diagnostic-only | `INPUTS` in `scripts/vp9_release_cost.py` owns the release-cost roster: `roster` refuses any other `maps.json` before capture writes or launches anything and before replay, and replay also requires the recorded input file IDs and hashes to equal it. Same-prefix, replaced, omitted, duplicate, reordered and relabeled input regressions are in `test_vp9_release_cost.py`; a twelve-character prefix cannot identify an input. `CELLS` and `PROFILE_CELLS` own the rosters in `scripts/vp9_release_attribution.py`; capture checks subprocess settings and work, and replay rechecks the complete recorded rosters. Configuration, missing/duplicate, counter-scope, profile-work and media-free replay regressions are in `test_vp9_release_attribution.py`. Types cannot prove what an external decoder or profiler ran |
| A decoder bit-identity gate compares raw sample bits before quantization, not only integer PCM output | Not enforced: judgment. The Opus round 3 plan requires per-packet raw `f32::to_bits()` equality as well as command-output equality; quantization can hide differences |
| A future Opus speed registration requires complete, current, full-length capacity evidence, not a smoke pass or a stored pass flag | `bench/audio-decode/capacity.py check-registrations` in `deny.yml` recomputes the closed receipt's counters, six-cell coverage, source binding and referenced hashes. Synthetic qualification and registration regressions reject partial work, changed bytes and terminal errors; the workflow regression executes the actual step and requires a refusal to fail it. Matching a future round's executable provenance to the binding remains review judgment |
| Capacity qualification requires complete oracle output, a kernel-enforced temporary-output maximum and verified pinned baseline libraries | The capacity validator reconciles reference/default counts with the complete presentation or MP4 model and refuses budgets smaller than observed simultaneous files. The runner requires a dedicated tmpfs of exactly the recorded size before child execution; Linux regressions exceed it through child-written files and streamed captures. `oracle_pin.verify_bin` owns oracle version checks. One parsed baseline-library family predicate governs both required-library admission and archive checking, including multi-component direct-path names, whose changed-byte regression refuses a bypass. The binding hashes all resolved dependencies. Runtime evidence cannot be proved by a declared number or a filename |
| A new measurement gate specifies its capture, comparison and failure report before the run, including unsupported calibration and exact presentation ordering | Not enforced by this repository: judgment. The quality-validation harness has separate regression coverage, not a check in this repository's CI. A generic prose check cannot prove capture or comparison semantics. The Opus round 3 plan requires a negative-test failure before any CoreAV command opens its draw |
| Extending a measurement method's checks also extends its pre-timing and completeness requirements | Not enforced: judgment. The Opus round 3 method names all three required check outcomes rather than retaining the earlier two-check wording |
| VP9 filter coverage requires matched pixels, effective contrasts and rejected crossed comparisons; a smoke run cannot judge coverage or launch the registered measurement inputs before merge | `validate` and `capture` in `scripts/vp9_filter_coverage.py` own the predicate and main-only boundary. The equal-pixel, weakened-comparator, stale-evidence and pre-merge regressions in `test_vp9_filter_coverage.py` enforce them; headers alone cannot prove pixel effects |
| A generated VP9 packet-copy check preserves the packet, not the auxiliary IVF wrapper's clock; the source encoding still uses its registered tick | `ivf` owns positive clock validation and the caller's explicit source-tick constraint. `test_packet_copy_may_change_the_container_tick_but_not_the_packet` accepts changed wrapper ticks while refusing source drift and zero ticks; capture still compares complete packet bytes |
| Filter-capture failure reports expose closed stage and error labels, never arbitrary exception arguments or tool stderr | The fixed phase assignments, `FAILURE_CODES` and tool-diagnostic labels in `vp9_filter_coverage.py` own the output. Both credential-marker failure regressions in `test_vp9_filter_coverage.py` check the retained report; external parsing exceptions cannot establish safe text |
| Instance-receipt staging uses distinct resolved upload and download directories | The launcher's pre-provisioning path guard and `test_host_receipt_staging_rejects_shared_or_aliased_directories_before_provision` reject the same directory and its symlink (`deny.yml`). Operator path aliases require a filesystem check |
