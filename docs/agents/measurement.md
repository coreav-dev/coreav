| A support report labels an inapplicable predicate as such, never as a measured fraction | Not enforced in this repository: judgment. Applicability and measured support are separate facts; a count of cases cannot establish a predicate that does not exist |

## VP9 pixel reconstruction

| Rule | Enforced by |
|---|---|
| A VP9 pixel-round implementation is gated by unchanged bit-exact checks; timing uses its verified merged commit only, and results follow the run in a separate pull request | `plan.json` owns the frozen run boundary. `merge_receipt` in `scripts/vp9_pixel_round.py` rejects unmerged or wrong-commit builds, acquisition and capture; its capture claims a content-bound bundle before execution, and replay rechecks raw pixels, packet work, rosters, profiles and source binding. `test_vp9_pixel_round.py` covers merge refusal, changed bytes, incomplete and duplicate work, timeouts, profile accounting and replay. External Git and tool execution require runtime checks; independent implementation review and the separate results pull request remain review judgment |
| VP9 replay credits only commands that match the registered binary, prepared input, decoder mode and profiler settings | One `invocation` factory owns capture and replay commands; the executor accepts workload labels rather than arbitrary argument lists. Replay requires exact retained arguments and checks the original, prepared-packet and binary manifests. Command-substitution regressions reject `/bin/true` in every phase, wrong binaries and inputs, changed affinity, hash mode, decoder threads and profile options. Runtime paths and retained artifacts require validation beyond Python types |
