# VideoToolbox

VideoToolbox encode, hardware status, and the macOS encoder measurement tools.

| Rule | Enforced by |
|---|---|
| The physical-host fingerprint regression matches every other host field and cannot pass when the fingerprint comparison is neutralized | The matching-host positive control reaches a guarded file-hash boundary, while the changed-fingerprint case requires exact `host_mismatch` before that boundary. `test_fingerprint_regression_detects_neutralized_hardware_comparison` applies the masking mutation and requires the original test to fail for that boundary. Types cannot establish which runtime predicate caused a test refusal |
| Hosted VideoToolbox software refusals never become availability or conformance, and the exemption expires when status is observable | The initial-only MissingHardwareFlag error requires a complete unique-ID scan. The hosted classifier and closed refusal schemas reject other conditions and observable status; native_preflight_manifest rejects the outcome before judged accounting. Rust/Python refusal, stale-exemption, preflight-ledger and workflow-argument regressions cover these boundaries (videotoolbox.yml, deny.yml). External native metadata and transported JSON require runtime checks |
| VideoToolbox unit fixtures that register sessions share the SERIAL guard with global-registry assertions | tests.rs owns the session-construction fixtures under the same SERIAL mutex; sys.rs keeps only CF-object parser fixtures. Guard acquisition in new fixtures remains review judgment: the public production constructor cannot require a test-only synchronization token |
| VideoToolbox hardware status never comes from a requested preference or an absent flag | Native identity uses the session hardware property or one exact session-EncoderID match in a bounded encoder list with an explicit CFBoolean flag. EncoderIDs are opaque bounded UTF-8, not path tokens; `encoder_identifier` owns Python readback and byte bounds. The external-query, native fractional fixture and opaque-ID regressions cover that boundary; encoder_list_hardware_requires_one_exact_id_and_explicit_boolean checks both flag values, missing or wrong flags, no match, duplicate matches, malformed objects, list bounds and cancellation (videotoolbox.yml). Types cannot establish external CF metadata |
| VideoToolbox cadence hints never replace rational source clocks or the floor-based keyframe bound | Settings owns nearest-whole-fps/ties-up rounding; native setup requires exact integer readback. The fractional exporter fixture checks original packet PTS/durations and keyframe bound, and test_integer_hint_is_requested_only_and_native_readback_stays_exact rejects requested-as-observed baseline hints and rounded source clocks (videotoolbox.yml). Types cannot establish framework or external trace values |
| VideoToolbox process-exit errors still reap the child, and group EPERM alone never proves absence | `kill_group` owns termination and accepts EPERM only after a nonblocking reap and a missing-group probe. `test_exit_registration_failure_still_kills_and_reaps_the_child` and `test_permission_error_is_absence_only_after_reaping_and_a_missing_group` cover watcher errors, live children and surviving groups (`videotoolbox.yml`). Types cannot establish kernel process state |
| VideoToolbox measurement executables bind to the candidate through reviewed clean-build records | `coreav_build.capture` owns source isolation, pinned toolchain and dependency-byte checks; `coreav_build_records` verifies both committed platform records, candidate tree, configuration and executable hashes. `test_coreav_build.py` covers changed source, configuration, target, toolchain, dependencies and binary identities (`videotoolbox.yml`). Provenance remains a reviewed-record trust boundary, not cryptographic source-to-binary attestation |
| Revalidating a sealed VideoToolbox evidence bundle never changes its hashed records | The sealed branch in `build_bundle` replays before any campaign write and keeps the transient report outside the bundle; `test_interrupted_sealed_revalidation_preserves_every_hashed_record` checks interruption, retry and unchanged bytes (`videotoolbox.yml`). A JSON record type cannot enforce filesystem write order |
| VideoToolbox quality bars apply to every available cell and covered height class, never a pooled roster | `quality` requires the three registered ten-input class groups and explicit uncovered 2160 accounting; `timing.replay` supplies each invocation's grouped deltas. `test_quality_denominator_medians_and_fixture_floors` rejects a class median hidden by the other groups, incomplete classes and per-input or fixture misses (`videotoolbox.yml`). Types cannot establish the contents of external measurement records |
| Judged VideoToolbox work requires a merged source freeze and a separately reviewed actual-build and host seal | `source_freeze` owns the immutable coverage, selection, source, fixture and tool comparisons, including exact two-way 2160 membership and evidence identities. `test_source_freeze.py` rejects missing or changed content, unobserved colour relabeled as fact, malformed progressive proof and changed seal identities. External source bytes and merged review records require runtime checks |
| Raw materialization never accepts decoder diagnostics, changed raw bytes or uncertain process cleanup | `preparation.materialize_one` owns source spooling, exact whole and per-frame comparisons and create-only output; `preparation_process.capture` makes cleanup uncertainty terminal. `test_preparation.py` covers exit-zero decoder errors, partial outputs, executable changes, publication faults and child cleanup (`videotoolbox.yml`). Types cannot establish external process or filesystem state |
| Host-gate traces never make a report larger than its replay reader can accept | Gate reports own only descriptors; `write_gate` and `bound_gate` share the 4 MiB limit, while `gate_baseline_files` owns bounded artifact readback and bundle transport preserves the directories. Capture/replay and large-trace regressions preserve complete files, refuse changed bytes and leave an existing report unchanged after an oversized publication attempt. External file sizes and retained bytes need runtime checks |
| CoreVideo plane storage, including padding, is initialized before any mutable byte slice is formed | `copy_frame` writes both checked plane ranges through raw pointers before creating slices; `test_native_plane_storage_is_initialized_before_byte_slices` requires that exact ordering and rejects both removed initializations (`deny.yml`). A byte slice cannot represent uninitialized native storage, and CoreVideo's allocation contract does not establish initialization |
| Only the Rust submission ledger returns recoverable VideoToolbox backpressure; an error after reserving native submission is terminal | `Session::submit_inner` maps native backpressure to a resource-limit failure, which `record` latches; `a_pool_limit_after_reservation_is_terminal_not_a_phantom_pending_frame` checks immediate refusal, retry and completion (`encoder-backends.yml`). The shared error type also describes recoverable pre-submission admission, so it cannot enforce the phase alone |
