```text
Serve these commands as Model Context Protocol tools over standard input and output, for agents (docs/design/mcp.md)

Usage: coreav mcp [OPTIONS]

Options:
      --root <DIR>         A directory the tools may read and write in; repeat it for more. Paths outside every root are refused. Default: the current directory
      --timeout <SECONDS>  Seconds one tool call may run before it is stopped [default: 600]
      --urls <WHICH>       Which URLs the tools read: `public` (https:// URLs of public addresses), `any` (as the command line, private addresses and http:// included) or `none` [default: public] [possible values: public, any, none]
  -h, --help               Print help
```
