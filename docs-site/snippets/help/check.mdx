```text
Check an MP4, MOV, Matroska or WebM file against an upload policy and print the verdict as JSON

Usage: coreav check --policy <POLICY> <FILE>

Arguments:
  <FILE>  The file to check

Options:
      --policy <POLICY>  The policy: a `coreav.policy/1` JSON file (docs/schema/policy-v1.md)
  -h, --help             Print help
```
