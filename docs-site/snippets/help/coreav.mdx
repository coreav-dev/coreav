```text
The coreav command: memory-safe probing of MP4/MOV, Matroska, WebM and MPEG transport stream files, local or at an HTTP(S) URL; clipping, splitting, joining, sanitizing, audio, subtitle and chapter extraction and HLS packaging of MP4/MOV files; remuxing of all of them to MP4; decoding of their audio to WAV; and upload policy checks

Usage: coreav [OPTIONS] <COMMAND>

Commands:
  probe              Describe an MP4, MOV, Matroska or WebM file as JSON
  clip               Cut a keyframe-aligned clip of an MP4/MOV file to MP4, without re-encoding
  split              Split an MP4/MOV file at keyframes into MP4 segments, without re-encoding. Together the segments hold every packet of the kept streams exactly once
  check              Check an MP4, MOV, Matroska or WebM file against an upload policy and print the verdict as JSON
  extract-audio      Copy the AAC audio track of an MP4/MOV file into an M4A file, without re-encoding
  decode-audio       Decode an audio track of an MP4/MOV, Matroska or WebM file to a WAV file (FLAC, MP3)
  remux              Rewrite an MP4/MOV, Matroska or WebM file as MP4 with the movie header first (faststart), without re-encoding
  extract-subtitles  Write the text subtitles (mov_text: 3GPP timed text or QuickTime text) of an MP4/MOV file as WebVTT
  chapters           Print the QuickTime chapter list of an MP4/MOV file as JSON
  sanitize           Rewrite an MP4/MOV file as MP4 without its metadata (location, device, dates), keeping only allowlisted boxes, without re-encoding
  join               Join MP4/MOV files that share a codec configuration into one MP4, without re-encoding
  hls                Serve an MP4/MOV file as HLS with fragmented MP4 (CMAF) segments, without re-encoding
  ffprobe            Experimental. Runs an ffprobe command line: ffprobe's own options, a supported subset. With --strict-safe (COREAV_STRICT_SAFE=1), for untrusted input, anything else is refused with exit status 4; without it, anything else runs the ffprobe program on PATH, FFmpeg's C code (docs/design/compat-cli.md). Values can differ from ffprobe's for MP4/MOV and MPEG-TS; Matroska/WebM agree on 98% or more of files for 99 of 101 keys (docs/measurements/compat-ffprobe.md). `coreav` run as `ffprobe` does the same
  ffmpeg             Runs an ffmpeg stream-copy command line (-c copy) with CoreAV's own writers: remuxing to MP4, clipping, segmenting and audio extraction to M4A, with ffmpeg's stream selection. With --strict-safe (COREAV_STRICT_SAFE=1), for untrusted input, anything else is refused with exit status 4; without it, anything else runs the ffmpeg program on PATH, FFmpeg's C code (docs/design/compat-cli.md). `coreav` run as `ffmpeg` does the same
  help               Print this message or the help of the given subcommand(s)

Options:
      --strict-safe  For services that read untrusted input: CoreAV never runs an ffmpeg or ffprobe program, which is FFmpeg's C code, as COREAV_STRICT_SAFE=1 does. `coreav ffprobe` and `coreav ffmpeg` refuse a command that is not native (exit status 4) instead of running it with FFmpeg, and a thumbnail or transcode never decodes or encodes with FFmpeg: a video only FFmpeg would decode, and an encode without an x264 program, are refused (exit status 4)
  -h, --help         Print help
  -V, --version      Print version
```
