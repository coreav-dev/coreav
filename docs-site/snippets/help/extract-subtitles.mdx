```text
Write the text subtitles (mov_text: 3GPP timed text or QuickTime text) of an MP4/MOV file as WebVTT

Usage: coreav extract-subtitles [OPTIONS] <INPUT> <OUTPUT>

Arguments:
  <INPUT>   The file to read
  <OUTPUT>  Where to write the WebVTT file: a new file, or `-` for standard output

Options:
      --stream <STREAM>  The subtitle stream index (default: the first text stream that is not a chapter track)
      --force            Overwrite existing writable regular files (symbolic links and multiply-linked Unix files are refused; a replaced file keeps its permissions)
  -h, --help             Print help
```
