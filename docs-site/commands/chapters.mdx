`coreav chapters FILE` prints the QuickTime chapter list of an MP4 or MOV file as a JSON document, [`coreav.chapters/1`](https://github.com/coreav-dev/coreav/blob/main/docs/schema/chapters-v1.md).

## Example

```sh
coreav chapters input.mp4
```
