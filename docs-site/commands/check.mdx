`coreav check --policy POLICY FILE` checks an MP4, MOV, Matroska, WebM or MPEG-TS file against an upload policy and prints the verdict ([`coreav.verdict/1`](https://github.com/coreav-dev/coreav/blob/main/docs/schema/verdict-v1.md)) on standard output. A policy is a [`coreav.policy/1`](https://github.com/coreav-dev/coreav/blob/main/docs/schema/policy-v1.md) JSON file that sets limits on codecs, resolution, duration, size and more.

MPEG-TS uses `coreav.probe-mpegts/2`. Its missing validity, data-location and sample-description fields reject under the default rules as `unknown`, not `unreadable`. To allow MPEG-TS, a policy must explicitly ignore those checks; resolution rules need `size_source: "declared"` because the document has no verified size bound. See [MPEG-TS policy mapping and missing evidence](https://github.com/coreav-dev/coreav/blob/main/docs/schema/policy-v1.md#mpeg-ts-mapping-and-missing-evidence) before using it as an upload gate.

| Exit status | Meaning |
|---|---|
| 0 | The file is accepted. |
| 1 | The file is rejected. The verdict on standard output lists the reasons. |
| 2 | The policy is not valid. |

## Example

```console
$ coreav check --policy web-upload.json input.mp4
{
  "policy": "web-upload",
  "reasons": [],
  "schema": "coreav.verdict/1",
  "verdict": "accept"
}
```

The repository has example policies in [`docs/schema/policy-examples`](https://github.com/coreav-dev/coreav/tree/main/docs/schema/policy-examples).
