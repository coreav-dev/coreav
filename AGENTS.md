# Rules for agents and contributors, and what enforces each

Read `CONTRIBUTING.md` and `.github/pull_request_template.md` first; design notes for each area are in `docs/design/`. This file pairs every rule with what enforces it, so a rule that nothing enforces is visible.

When a review corrects a mistake, fix it and add its rule here. If the rule is already here and nothing enforces it, that is a repeat: in the same change, enforce it at the highest level that works (one owner or one way to do it, then a type, then a check whose error names the fix, then a test) and say why a higher level did not. Drop a row once its mistake cannot happen.

| Rule | Enforced by |
|---|---|
| Hosted VideoToolbox software refusals never become availability or conformance, and the exemption expires when status is observable | The initial-only MissingHardwareFlag error requires a complete unique-ID scan. The hosted classifier and closed refusal schemas reject other conditions and observable status; native_preflight_manifest rejects the outcome before judged accounting. Rust/Python refusal, stale-exemption, preflight-ledger and workflow-argument regressions cover these boundaries (videotoolbox.yml, deny.yml). External native metadata and transported JSON require runtime checks |
| VideoToolbox unit fixtures that register sessions share the SERIAL guard with global-registry assertions | tests.rs owns the session-construction fixtures under the same SERIAL mutex; sys.rs keeps only CF-object parser fixtures. Guard acquisition in new fixtures remains review judgment: the public production constructor cannot require a test-only synchronization token |
| VideoToolbox hardware status never comes from a requested preference or an absent flag | Native identity uses the session hardware property or one exact session-EncoderID match in a bounded encoder list with an explicit CFBoolean flag. encoder_list_hardware_requires_one_exact_id_and_explicit_boolean checks both flag values, missing or wrong flags, no match, duplicate matches, malformed objects, list bounds and cancellation (videotoolbox.yml). Types cannot establish external CF metadata |
| VideoToolbox cadence hints never replace rational source clocks or the floor-based keyframe bound | Settings owns nearest-whole-fps/ties-up rounding; native setup requires exact integer readback. The fractional exporter fixture checks original packet PTS/durations and keyframe bound, and test_integer_hint_is_observed_separately_from_the_exact_source_clock rejects missing or mismatched baseline hints and rounded source clocks (videotoolbox.yml). Types cannot establish framework or external trace values |
| VideoToolbox process-exit errors still reap the child, and group EPERM alone never proves absence | `kill_group` owns termination and accepts EPERM only after a nonblocking reap and a missing-group probe. `test_exit_registration_failure_still_kills_and_reaps_the_child` and `test_permission_error_is_absence_only_after_reaping_and_a_missing_group` cover watcher errors, live children and surviving groups (`videotoolbox.yml`). Types cannot establish kernel process state |
| G1 hash ordering counts identical prepared bytes once, regardless of parent, with an encoder-blind representative chosen before slot selection | Not enforced: judgment until freeze tooling exists. The duplicate rule in `docs/design/h264-encoder.md` orders representatives by full-original SHA-256 and stable parent identifier, refuses an unresolved tie and excludes other copies from all slots. Prose cannot prove external byte identity |
| VP9 decoding budgets retained capacities and all new packet allocations, including copied outputs, before publishing frame state | `Memory` owns checked charges and fallible buffer creation; the fixed reference pool and inline parse/counter state remove shared and boxed allocation. Crate clippy rules reject production `Box`, `Arc`, `Rc` and infallible reserve methods; they cannot identify every future allocating iterator or deep clone, so keeping those out of decoder paths remains review judgment |

| G1 conformance preserves the oracle's native planar format and retains process failure diagnostics, including timeouts | One shared `capture` owns conformance and measurement process records, including the decoder's streamed binary output. `test_full_range_native_pixel_format_is_not_converted` rejects wrong range, format, or geometry; failure and timeout regressions retain partial output and status, re-raising the original timeout instead of accepting it |
| Small G1 pictures retain the level's access-unit envelope instead of an unregistered fraction of their raw size | `a_small_textured_picture_uses_the_level_ceiling_not_a_raw_size_fraction` encodes a one-macroblock picture above 192 NAL bytes, while preserving a caller's explicit smaller bound |
| The JM downloader supplements a missing intermediate only from the exact pinned certificate and a chain to existing roots; it never disables TLS verification | The bundle consumes a single PEM reconstructed from validated DER, not the downloaded multi-certificate input. `test_jm_bundle_drops_a_trailing_unpinned_certificate` proves an appended synthetic CA stays untrusted; `test_jm_archive_fetch_requires_pinned_and_root_verified_intermediate` refuses hash or root-validation failures before archive fetch |
| G1 VUI colour combinations obey the specification, and cached RD summaries are replayed from complete raw metric output | `unspecified_primaries_cannot_signal_derived_colour_matrices` rejects forbidden derived matrices; `test_aggregate_mutation_and_missing_metric_detail_fail` requires 60 finite frame scores, their arithmetic mean, chroma scores, and replayable process records.
