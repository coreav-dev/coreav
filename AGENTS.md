# Rules for agents and contributors, and what enforces each

Read `CONTRIBUTING.md` and `.github/pull_request_template.md` first; design notes for each area are in `docs/design/`. This file pairs every rule with what enforces it, so a rule that nothing enforces is visible.

When a review corrects a mistake, fix it and add its rule here. If the rule is already here and nothing enforces it, that is a repeat: in the same change, enforce it at the highest level that works (one owner or one way to do it, then a type, then a check whose error names the fix, then a test) and say why a higher level did not. Drop a row once its mistake cannot happen.

| Rule | Enforced by |
|---|---|
| Every resolved audio encoder is authorized before executable discovery, including implicit audio-only and AVI defaults | `encode::authorize_audio` exhaustively delegates every codec to `StrictSafe` for video, audio-only and AVI encoding. The resolved-encoder unit regression checks the codec refusal before platform sandbox checks; `ffmpeg_strict_safe_authorizes_resolved_audio_before_discovery` covers implicit and explicit AAC/MP3, MP3 in AVI, both strict-safe switches and a renamed encoder that records any invocation, requiring exit 4, no invocation and no output (`ci.yml`) |
| AVI MP3 uses the shared PCM feeder and audited reader without changing its complete frames or packet clock | `audio::encode_with` owns process settings, sample feeding and readback for both callers; `EncodedAudio::mp3_packets` only retains checked frames. `ffmpeg_avi_mp3_keeps_the_previous_complete_file_bytes` compares entire AVI files with the former raw-pipe encoder invocation and unchanged AVI writer, including mono/stereo, MPEG rate families, default/explicit bitrates and EOF boundaries (`ci.yml`). An external encoder's byte identity needs a runtime comparison |
| MP3 encoder readback audits the entire spool, rejects auxiliary/state changes and verifies frame timing within Matroska quantization, under the encode deadline | `Packets::with_audit` owns the full-file walk; packet fields retain `CodecState` and block additions for the MP3 boundary to reject. `full_output_structure_auxiliary_data_and_timestamps_are_checked` covers appended bytes/segments, additions, codec state, duration and reordered timestamps. `TimedSource` checks cached parser reads too; `readback_checks_the_deadline_inside_parser_reads` requires timeout classification and at most one underlying read after a controlled deadline crossing |
| MP3 encoding validates the full PCM count including its EOF zero guard, then removes that explicit guard in the gapless tag | The shared audio feeder counts original and fed samples separately; `mp3::read_output` requires exact CodecDelay/DiscardPadding accounting. `ffmpeg_mp3_eof_guard_preserves_exact_boundary_lengths` checks seekable oracle decoding and ffprobe at residues 1, 46 and 47 in all three MPEG rate families; malformed, truncated and out-of-bound output is covered by `mp3` unit tests and the `mp3_output` fuzz target |
| Audio-only encoding refuses source offsets, tags and dispositions it cannot preserve, and never treats a concat list as a media file | The shared concat-encoding guard and `audio::plan` own these refusals; `ffmpeg_audio_only_refuses_unpreserved_source_properties` covers positive input origins, delayed audio, custom handlers, forced dispositions and concat in the whole transcode fixture target (`ci.yml`). Types cannot prove source metadata or command semantics |
